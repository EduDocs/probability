## Purpose
Set expectations for the notes: scope (an introduction to probability), audience (calculus background, some programming), and the intended role of computing as a tool for intuition and problem solving.

## Key points / outline
- Notes are an introduction to probabilistic concepts and techniques.
- Designed for a 45-hour semester course.
- Reader prerequisites: calculus (sequences, series, derivatives, integrals).
- Programming skills help for the computing material and examples.
- Probability fits computers naturally: simulation, imaging, and graphical illustration of difficult concepts.
- Computers also handle problems without closed-form solutions.
- Pointer to an external interactive resource (Seeing Theory).
